# Unstuck: Your Student Launchpad

UNSTUCK – Complete AI Website Generation Prompt

Build a modern, responsive, production-ready full-stack web application called UNSTUCK.

Project Overview

UNSTUCK is a student collaboration platform that helps students:

Find teammates for hackathons and projects

Discover events and competitions

Showcase projects

Ask technical questions and receive community support

Build professional student profiles

The design should feel like a combination of:

LinkedIn (professional profiles)

GitHub (projects)

Stack Overflow (community Q&A)

Unstop (events and competitions)

Use a clean, modern UI with rounded cards, smooth animations, glassmorphism effects, dark/light mode support, and a professional student-focused design.
